# Airbnb Analysis Dashboard — Tableau

## Project Overview
This project analyzes Airbnb listing data to explore pricing, neighbourhood ratings, bed counts and host joining trends.

## Tools Used
- Tableau
- Excel / CSV

## Dashboard Charts
- Average Price by Zipcode
- Top 10 Neighbourhoods by Rating
- Total Beds by Neighbourhood and Room Type
- Average Price by Host Joining Year

## Key Skills Demonstrated
- Data visualization
- Data exploration
- Dashboard design
- Filters and interactive analysis
